# FADIVS Twitch Full-Stream Bot

Бот `twitch.tv/fadivs` арнасын бақылайды. Стрим аяқталғаннан кейін сәйкес толық VOD-тың Twitch архивінде пайда болуын күтеді, видеоны бір үздіксіз 9:16 MP4 форматына өңдейді және `@autoclipsfadivs` Telegram каналына жібереді.

**Бұл highlights/shorts генераторы емес.** Код видеоны уақыт бойынша кесуге, 30–60 секундтық бөліктерге бөлуге немесе үзінді таңдауға тырыспайды. Бастапқы VOD-тың ұзақтығын тексереді және экспорт айтарлықтай қысқарса, оны жіберуден бас тартады.

> **Нақты шектеулер:** Twitch API VOD туралы метадеректер береді, ал VOD жүктеу үшін `yt-dlp` қолданылады. Тек өзіңе тиесілі немесе жүктеп/өңдеуге рұқсатың бар VOD-тарды өңде. Жеке, жазылыммен қорғалған немесе қолжетімсіз жазбалар автоматты жүктелмеуі мүмкін. Бот әрқашан қосулы серверді және көп диск кеңістігін қажет етеді.

## Не істейді?

- Twitch арнасының live/offline күйін тексереді.
- Тек бот жұмыс істеп тұрған кезде байқалған live сессияның архивін іздейді; алғашқы іске қосылғанда ескі VOD-ты кездейсоқ жарияламайды.
- Толық архивті жүктеп, бапталған камера аймағын жоғарғы панельге және ойын/контент аймағын төменгі панельге қояды.
- H.264/AAC MP4 форматындағы бір файл жасайды және ұзақтығын бастапқы видеоға салыстырады.
- VOD ID-ін күй файлына сақтайды; қайта іске қосылса, аяқталмаған жұмысты қайта жалғастыруға тырысады.
- Файл шектеуге сыймаса, оны үнсіз бөлшектемей, нақты қатемен тоқтайды және видео файлын қалдырады.

## Орнату

### 1. Telegram

1. Telegram-да [@BotFather](https://t.me/BotFather) арқылы бот жаса және токенін ал.
2. Ботты `@autoclipsfadivs` каналына әкімші ретінде қос; хабарлама/видео жариялауға рұқсат бер.
3. Токенді тек сервердің `.env` файлына енгіз. Оны GitHub-қа қоспа.

### 2. Twitch API

1. [Twitch Developer Console](https://dev.twitch.tv/console/apps) арқылы app жаса.
2. Client ID және Client Secret ал.
3. Екеуін де `.env` ішіне енгіз. Client Secret-ті ешкімге жіберме.

### 3. Сервер мен конфигурация

Docker және Docker Compose орнатылған, 24/7 жұмыс істейтін VPS/сервер қажет. Екі сағаттық VOD жүктеу және қайта кодтау бірнеше сағатқа созылуы және ондаған гигабайт дискілік орын сұрауы мүмкін.

```bash
cp .env.example .env
nano .env
mkdir -p data
docker compose up -d --build
docker compose logs -f
```

`TELEGRAM_BOT_TOKEN`, `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET` мәндерін толтыр. Қалған параметрлерді VOD-қа сай ретте. Windows-та немесе телефонда локалды іске қосу үшін Docker Desktop/сервер қажет; GitHub-та файлдарды сақтау боттың өзін іске қоспайды.

### 4. Telegram файл өлшемі

Telegram-ның ресми бұлттық Bot API-і бот жіберетін құжат/видео үшін қазіргі құжаттама бойынша **50 MB** шегін белгілейді. Сондықтан толық стрим әдетте сол шектен үлкен болады. Ол кезде бот видеоны бөлмейді және жүктеуді тоқтатып, файлды серверде сақтайды.

Бір үлкен файлды жіберу үшін Telegram-ның **жергілікті Bot API серверін** орнатуға болады; ресми нұсқаулықта жергілікті сервер үшін 2000 MB-қа дейінгі жүктеу шегі көрсетілген. Бұл қосымша серверлік конфигурация мен `my.telegram.org` сайтынан `api_id` және `api_hash` алуды талап етеді.

Қажет болса:

1. `.env` файлына `TELEGRAM_API_ID=...`, `TELEGRAM_API_HASH=...` қос.
2. `.env` ішіне `TELEGRAM_API_BASE_URL=http://telegram-bot-api:8081` қой.
3. Telegram ботын жергілікті API серверіне көшіру алдындағы ресми `logOut` талабын орында (Telegram жергілікті Bot API нұсқаулығын қара).
4. Іске қос:

```bash
docker compose -f docker-compose.yml -f docker-compose.large-upload.yml up -d --build
docker compose logs -f
```

Бұл режим 2000 MB шегінен асатын файлдарды жіберуге кепілдік бермейді. Конфигурациядағы 1850 MB — қауіпсіздік қоры бар тексеру шегі. Өте ұзын немесе жоғары битрейтті VOD сыя алмаса, код оны бөліктерге бөлмейді.

## Кадр аймақтарын баптау

`CAM_X`, `CAM_Y`, `CAM_W`, `CAM_H` және `GAME_X`, `GAME_Y`, `GAME_W`, `GAME_H` бастапқы Twitch видеосындағы пайыздық координаталар. Әдепкі баптау бастапқы кадрдың жоғарғы жартысын жоғарыға, төменгі жартысын төменге қояды. Ол камера аймағы дәл сондай жерде дегенді білдірмейді.

Егер камера мен ойын бір кадрға араласып тұрса, тек crop арқылы ойыннан камераны автоматты түрде бөліп алу мүмкін емес. Әр аймақтың координаталарын түпнұсқа VOD-қа сәйкес өзгерту керек. Камера/ойын бөлек жазылса, арнайы input mapping қосуға болады — бұл қазіргі жобаның автоматты мүмкіндігі емес.

Мысалы, тек нақты кадрды көріп тексергеннен кейін ғана `CAM_*` пен `GAME_*` координаталарын өзгертіңіз. `OUTPUT_WIDTH=720`, `OUTPUT_HEIGHT=1280` — вертикал формат; екі панельдің биіктігі тең.

## Файлдарды сақтау

Әдепкіде видео сәтті Telegram-ға жіберілген соң уақытша файлдар өшіріледі. `KEEP_FILES=true` болса, файлдар `data/` бумасында сақталады. `data/state.json` өңделген VOD ID-ін сақтайды.

## Тест

Python ортасында тәуелділіктерді орнатқаннан кейін:

```bash
python -m unittest test_project.py
python -m py_compile bot.py config.py editor.py state.py telegram_upload.py twitch.py
```

Бұл тесттер конфигурация, crop өрнектері және битрейт парсерін тексереді; олар Twitch/Telegram тіркелгісін немесе нақты ұзын VOD-ты тексермейді.

## Қауіпсіздік

- `.env`, Twitch cookies, bot token, Client Secret, Telegram API hash және кез келген жеке OAuth токенді GitHub-қа жүктеме.
- `.env.example` ішінде тек placeholder мәндер болуы тиіс.
- VOD тек өзіңе тиесілі немесе өңдеуге нақты рұқсатың бар болуы керек.
- Қызметтік логтарда токендер әдейі шығарылмайды.
